## 一、FRED API

### 基本信息
- **官网**: https://fred.stlouisfed.org/
- **API文档**: https://fred.stlouisfed.org/docs/api/fred/
- **费用**: 免费，需注册获取API Key

### FRED API代码示例

```python
from fredapi import Fred
fred = Fred(api_key='YOUR_API_KEY_HERE')

# 获取10年期美债收益率
dgs10 = fred.get_series('DGS10')

# 获取ISM PMI
pmi = fred.get_series('NAPM')

# 获取期限溢价
tp = fred.get_series('THREEFYTP10')

# 批量获取
data = fred.get_series(['DGS10', 'DGS2', 'DFII10', 'T10YIE', 'THREEFYTP10'])
```

### 10Y名义利率三因子分解说明
根据FRED-MD文档和美联储三因子期限结构模型：
- **THREEFYLN10**: 预期未来短期利率的平均值（Level factor）
- **THREEFYSP10**: 期限溢价（Spread factor / Term Premium）  
- **THREEFYTP10**: Kim-Wright 10Y期限溢价（与ACM模型不同，是FRB三因子模型）
- 三者之和 ≈ 10Y名义收益率

> ⚠️ 注意：THREEFYTP10（FRB三因子模型）与 ACMTP10（NY-Fed Adrian-Crump-Moench模型）是两个不同的期限溢价估计。看板中建议同时展示或明确标注使用的是哪个模型。

### 不可用/需替代的指标
- **无**。上述所有指标均可通过FRED API直接获取。

### 稳定性评估
- ⭐⭐⭐⭐⭐ 非常稳定。美联储维护，数据更新及时，API文档完善
- 日频数据通常在工作日下午4-5点(ET)更新
- 月度数据在发布后1-2个工作日内入库FRED

### yfinance代码示例

```python
import yfinance as yf

# 下载单个标的历史数据
sp500 = yf.Ticker("^GSPC")
hist = sp500.history(period="max")  # 全部历史数据

data = yf.download(["^GSPC", "^IXIC", "^DJI", "GC=F", "CL=F", "^VIX"],
                   start="2000-01-01", end="2026-07-26",
                   group_by="ticker")

# 获取VIX数据
vix = yf.Ticker("^VIX").history(period="5y")
```

### 稳定性评估
- ⭐⭐⭐ 中等稳定。非官方接口，可能遭遇速率限制(429)或IP封禁
- **风险点**: Yahoo Finance近年来加强了对爬虫的防护，高频请求容易被封
- **建议**:
  - 每日仅拉取一次数据，做本地缓存
  - 实现指数退避重试机制
  - 备选方案：FRED已有SP500、VIXCLS数据；利率数据也有FRED覆盖

### 备选方案

### 4.4 股权风险溢价 (ERP)

| 项目 | 详情 |
|------|------|
| 是否直接获取 | ❌ 需**自行计算** |
| 计算公式 | ERP = E/P - 10Y国债收益率 |
| E/P | 盈利收益率 = 1/PE（市盈率倒数） |
| 所需数据 | ① PE数据（AKShare/FRED） ② 10Y国债收益率（FRED/AKShare） |
| 美股ERP | S&P 500 E/P - 10Y美债收益率 |
| A股ERP | 沪深300 E/P - 中国10Y国债收益率 |

**自建计算方案**:
```python
# 美股ERP
sp500_pe = 25.0  # 从yfinance或其他源获取
sp500_ep = 1 / sp500_pe  # 盈利收益率
us_10y_yield = 4.3 / 100  # FRED DGS10
us_erp = sp500_ep - us_10y_yield

# A股ERP
hs300_pe = 14.13  # AKShare获取
hs300_ep = 1 / hs300_pe  # 盈利收益率
cn_10y_yield = 1.76 / 100  # AKShare获取
cn_erp = hs300_ep - cn_10y_yield
```

**参考**: Damodaran每年更新ERP估计: https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/ctryprem.html

## 五、总结与建议

### 5.1 指标分类汇总

#### ✅ 可直接获取的指标（约75%）
| 数据源 | 指标数量 | 代表指标 |
|--------|---------|---------|
| FRED API | ~19个 | GDP、CPI、PPI、失业率、PMI、利率系列、期限溢价、SP500、VIX、美联储资产负债表、OECD CLI |
| Yahoo Finance | ~10个 | 美股三大指数、黄金/原油/铜期货、VIX、美元指数、10Y国债、比特币 |
| AKShare | ~17个 | A股指数、国债收益率、CPI/PPI/PMI、社融/M2、PE/PB |
| Shiller官网 | 1个 | CAPE（Excel下载） |
| WGC | 1个 | 央行购金（Excel下载） |

#### 🔧 需要自行计算的指标
| 指标 | 所需原始数据 | 计算方式 |
|------|-------------|---------|
| 巴菲特指标 | 总市值(FRED/Wilshire) + GDP(FRED) | 总市值 / GDP |
| 股权风险溢价(ERP) | PE倒数(E/P) + 无风险利率 | E/P - 10Y国债收益率 |
| PE/PB历史分位 | PE/PB历史序列(AKShare) | 当前值在历史序列中的百分位 |
| AAII情绪差 | 看多% - 看空% | 需获取AAII原始数据后计算 |

#### ⚠️ 获取难度较大的指标
| 指标 | 难度 | 原因 | 建议 |
|------|------|------|------|
| AAII仓位指标 | 高 | 无API，需会员或爬虫 | 用VIX+Put/Call Ratio替代 |
| 10Y利率三因子分解 | 中 | FRED有三个系列但需理解模型差异 | 直接获取THREEFY系列 |

### 5.2 数据源稳定性评级与备选方案

| 数据源 | 稳定性 | 风险 | 备选方案 |
|--------|--------|------|---------|
| FRED API | ⭐⭐⭐⭐⭐ | 极低 | 无需备选 |
| AKShare | ⭐⭐⭐⭐ | 中低（数据源网站改版） | 及时更新库版本；Tushare作为备选 |
| Yahoo Finance | ⭐⭐⭐ | 中（速率限制/IP封禁） | FRED覆盖大部分指标；AKShare覆盖商品 |
| WGC | ⭐⭐⭐⭐ | 低（手动下载，但数据源稳定） | 需编写定时下载脚本 |
| Shiller | ⭐⭐⭐ | 中低（文件格式可能变动） | Multpl.com作为备选展示 |

### 5.3 数据更新频率建议

| 数据类型 | 建议更新频率 | 说明 |
|---------|------------|------|
| 日频行情数据(指数/期货/利率) | 每工作日收盘后 | 北京时间每日16:00后更新 |
| 周频数据(美联储资产负债表) | 每周四 | 美联储每周四发布 |
| 月频宏观数据(CPI/PPI/PMI等) | 月度发布后1-2天 | 各指标发布日期不同 |
| AAII情绪 | 每周四 | 约10:30 ET |
| 央行购金 | 每月初 | 滞后2个月 |
| CAPE | 每月 | Shiller月度更新 |
| 巴菲特指标 | 每季度 | GDP为季度数据 |
| OECD CLI | 每月 | OECD月度更新 |

### 5.4 技术架构建议

```
数据获取层:
├── FRED API (fredapi) ──── 美国宏观/利率/期限溢价
├── yfinance ──────────── 美股/商品/汇率/VIX (备选:FRED)
├── AKShare ─────────────── 中国宏观/A股/中国债券
├── 定时下载 ─────────────── Shiller CAPE / WGC央行购金
└── 自行计算 ─────────────── 巴菲特指标/ERP/PE分位

数据处理层:
├── 统一时区处理 (UTC / 北京时间)
├── 频率对齐 (日频→月频 或 前值填充)
├── 缺失值处理
└── 历史分位计算

存储层:
├── 本地Parquet/SQLite缓存 (避免重复拉取)
└── 增量更新机制
```

### 5.5 优先级实施建议

1. **第一阶段**: 先接入FRED API（覆盖约50%指标，最稳定）
2. **第二阶段**: 接入AKShare（覆盖中国市场数据）
3. **第三阶段**: 接入yfinance（补充商品/汇率数据，做好缓存）
4. **第四阶段**: 实现Shiller CAPE和WGC数据的定时下载解析
5. **第五阶段**: 实现自建计算指标（ERP、巴菲特指标、PE分位）
